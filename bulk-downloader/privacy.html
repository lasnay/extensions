Bulk Image & File Downloader

Dernière mise à jour : 6 novembre 2026

Résumé

Bulk Image & File Downloader ne collecte, ne stocke sur un serveur, ne vend ni ne partage aucune donnée personnelle. Il n'a ni système de comptes, ni statistiques, ni publicité.

Ce que l'extension lit

Lorsque vous cliquez sur l'icône de l'extension (ou utilisez son raccourci clavier ou son menu clic droit), elle lit la page web sur laquelle vous êtes afin d'en lister les images et les fichiers téléchargeables. Ces informations restent dans votre navigateur et sont supprimées quand vous fermez la fenêtre de l'extension.

Ce que l'extension enregistre

Uniquement vos propres préférences (limites de défilement, thème, langue, nom du dossier de téléchargement, limites de défilement par site). Elles sont enregistrées avec storage.sync de Chrome : elles sont conservées dans votre profil Chrome et peuvent être synchronisées par Chrome entre vos propres appareils. Elles ne sont jamais envoyées à l'éditeur ni à un tiers.

Requêtes réseau

L'extension télécharge les fichiers que vous sélectionnez depuis les adresses web où la page les héberge. Sa seule autre requête réseau est le message d'avis facultatif décrit ci-dessous ; elle n'envoie jamais rien d'autre au développeur.

Messages d'avis

Si vous utilisez « Aide et avis » dans les paramètres, le message que vous écrivez est envoyé à un formulaire Google Forms géré par l'éditeur, avec le nom de l'extension et le type de message. Si vous cochez la case, sont aussi joints : la version de l'extension, la langue et le type de navigateur. Jamais les adresses ni le contenu de vos onglets. Aucune adresse e-mail n'est demandée. Ne mettez pas d'informations personnelles dans votre message.

Autorisations

Les autorisations demandées (onglet actif, scripting, téléchargements, stockage, menus contextuels, accès à tous les sites) servent uniquement aux fonctions décrites ci-dessus. La justification de chacune figure dans la fiche du Chrome Web Store.

Enfants

L'extension ne s'adresse pas aux enfants et ne collecte de données sur personne.

Modifications

Si cette politique change, la date ci-dessus sera mise à jour.

Summary

Bulk Image & File Downloader does not collect, store on a server, sell or share any personal data. It has no account system, no analytics and no advertising.

What the extension reads

When you click the extension icon (or use its keyboard shortcut or right-click menu), it reads the web page you are on in order to list its images and downloadable files. This information stays in your browser and is discarded when you close the popup.

What the extension stores

Only your own preferences (scroll limits, theme, language, download folder name, per-site scroll limits). They are saved with Chrome's storage.sync, which means they are kept in your Chrome profile and may be synchronised by Chrome between your own devices. They are never sent to us or to any third party.

Network requests

The extension downloads the files you select from the web addresses where the page hosts them. Its only other network request is the optional feedback message described below; it never sends anything else to the developer.

Feedback messages

If you use "Help and feedback" in the settings, the message you write is sent to a Google Forms form managed by the publisher, with the extension name and the message type. If you tick the box, the extension version, language and browser type are also attached. Never the addresses or content of your tabs. No email address is requested. Please do not put personal information in your message.

Permissions

The permissions requested (active tab, scripting, downloads, storage, context menus, access to all sites) are used only for the features described above. See the store listing for the justification of each one.

Children

The extension is not directed at children and collects no data from anyone.
