Privacy policy

Universal Dark Mode

Dernière mise à jour : 6 novembre 2026

Universal Dark Mode ne collecte, ne vend et ne transmet aucune donnée personnelle automatiquement. Seul un message d'avis que vous choisissez d'envoyer vous-même est transmis (voir ci-dessous).

Données traitées

  • Vos préférences (mode, teinte, luminosité, liste des sites exclus, réglages par site) sont enregistrées avec l'API de stockage de Chrome. Si la synchronisation Chrome est activée, Google les synchronise entre vos appareils ; l'extension n'y a accès que localement.
  • Une petite valeur technique (udm-last) est enregistrée dans le stockage local de chaque site visité. Elle mémorise seulement si le mode sombre était actif, pour éviter un flash blanc au chargement suivant.
  • Le contenu des pages est analysé uniquement dans votre navigateur, pour lire les couleurs et les remplacer. Rien n'est enregistré ni envoyé.
  • Vos messages d'avis : si vous utilisez « Aide et avis » dans les paramètres, le message que vous écrivez est envoyé à un formulaire Google Forms géré par l'éditeur, avec le nom de l'extension et le type de message. Si vous cochez la case correspondante, sont aussi joints : la version de l'extension, la langue et le type de navigateur. Jamais les adresses ni le contenu de vos pages. Aucune adresse e-mail n'est demandée. Ne mettez pas d'informations personnelles dans votre message.

Ce que l'extension ne fait pas

  • Aucun serveur de l'éditeur, aucune statistique, aucun traceur, aucune publicité.
  • Aucun historique de navigation n'est conservé.
  • Aucun code n'est téléchargé depuis Internet.

Last updated: 6 November 2026

Universal Dark Mode does not automatically collect, sell or transmit any personal data. Only a feedback message that you choose to send yourself is transmitted (see below).

Data processed

  • Your preferences (mode, tint, brightness, list of excluded sites, per-site settings) are stored with Chrome's storage API. If Chrome sync is turned on, Google syncs them between your devices; the extension only has local access to them.
  • A small technical value (udm-last) is stored in the local storage of each site you visit. It only remembers whether dark mode was active, to avoid a white flash on the next load.
  • Page content is analysed only in your browser, to read the colours and replace them. Nothing is stored or sent.
  • Your feedback messages: if you use "Help and feedback" in the settings, the message you write is sent to a Google Forms form run by the publisher, with the extension name and the message type. If you tick the matching box, the extension version, language and browser type are also attached. Never the addresses or content of your pages. No email address is requested. Do not put personal information in your message.

What the extension does not do

  • No publisher server, no statistics, no trackers, no ads.
  • No browsing history is kept.
  • No code is downloaded from the Internet.
